# BabyJose Jewelry

Elegant AI-powered jewelry showcase website featuring engagement collections, luxury jewelry displays, smart AI recommendations, shopping cart functionality, and responsive premium UI.

## Live Demo

https://anushastefyj.github.io/BabyJose-Jewelry/

---

## Features

- Luxury Engagement Ring Collection
- Interactive Shopping Cart
- AI-Based Jewelry Recommendations
- Fully Responsive Modern UI
- Elegant Animations & Toast Notifications
- Simulated Secure Checkout System
- Premium Jewelry-Themed Design
- Fast and Lightweight Frontend
